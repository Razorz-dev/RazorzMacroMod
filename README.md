# RazorzMacroMod
Macro &amp; Keybind Mod for Minecraft 1.21+ (NeoForge &amp; Fabric)
## Features
- Full keyboard macro binding
- Powerful scripting system
- Visual cooldown timer overlay
- Chat trigger automation
- External script file support
